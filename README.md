PulsePlayer 🎵
A lightweight and feature-rich desktop media player built in C++ using CMake. PulsePlayer provides a clean interface for local library management, custom playlists, online streaming features, and seamless information panels.

🚀 Features
Library Management: Efficiently organize, browse, and play your local music and media collection (library.h).

Custom Playlists: Create, save, and manage custom playlists on the fly (playlists.h).

Online Integration: Integrated online capabilities for streaming or fetching remote media content (online.h, google.h).

Interactive UI: User-friendly interface powered by structured dialogs and panels (ui.h, importdialog.h, infopanel.h, widgets.h).
